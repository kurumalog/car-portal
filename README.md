# car-portal（自動車なんでも相談所）

公的データ＋AI要約＋わかりやすいUI を自動車業界に転用する構想の試作版。
国内9メーカーの全現行車種をグレード単位でデータベース化し、各車種ページに
リコール履歴・安全性能評価・維持費・中古相場の4データ軸を載せる構成を目指す。

## 現状
- マツダ全10車種・計80グレード分のデータを収集済み（`car-spec-template.csv`）
- CSV → JSON変換スクリプト（`scripts/build-data.js`）
- 検索付き一覧ページ・車種詳細ページの試作（`site/`）
- 4データ軸（リコール履歴・JNCAP・維持費・中古相場）は未実装（枠のみ）

## ローカルでの確認方法
```
cd site
python3 -m http.server 8000
```
ブラウザで http://localhost:8000/ を開く。
